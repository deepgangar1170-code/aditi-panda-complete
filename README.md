# Aditi (PANDA) Birthday Website

A complete birthday website built with React + Vite.

## Publish on GitHub Pages
1. Create a new public repository named **aditi-panda-complete**.
2. Upload the contents of this folder to the repository root, including the hidden `.github` folder.
3. In GitHub, open **Settings → Pages** and choose **GitHub Actions** as the source.
4. Open **Actions** and wait for “Deploy birthday website” to finish.
5. Website address: https://deepgangar1170-code.github.io/aditi-panda-complete/

If you choose another repository name, update `base` in `vite.config.js` to `"/YOUR-REPOSITORY-NAME/"`.

Includes birthday greeting, Memory Lane, photo gallery, six Open When letters, reasons list, girlfriend terms, Panda Zone, couple quiz, interactive cake, music upload, and the final romantic date invitation letter.

Note: photos and music uploaded on the page are local to that browser/device. They are not automatically shared with Aditi. To make photos visible to her, add them as website assets and embed them in the page.
